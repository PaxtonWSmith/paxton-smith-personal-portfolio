Place your resume PDF in this folder with the exact name `resume.pdf`.

Usage:
- Save your PDF as `resume.pdf` and put it in this `public/` folder.
- The site already includes a "Download Resume" button that links to `/resume.pdf`.

Example path in project:
`frontend/public/resume.pdf`

After adding the file, reload your site and the button will download the PDF.

If you want this repo to contain your resume, rename your file to `resume.pdf` and commit it.

Note: Do not commit sensitive personal data if this repository is public.
